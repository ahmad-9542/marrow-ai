# MORROW AI

A responsive, editorial-style concept website for a fictional independent AI research and technology company. The project presents a human-centred approach to practical AI through product interface concepts, explanatory diagrams and a pure HTML/CSS contact form—with **zero JavaScript required**.

**MORROW AI, its products, team members and contact address are fictional concept content created for a college Web Development assignment.** The interface mockups are visual demonstrations and do not represent available commercial products. The contact form does not send or store messages.

## Technology

- **HTML5** for semantic structure and native form validation
- **CSS3** for layout, responsive behavior, mobile menu toggle, form confirmation state, illustrations and product mockups
- **Google Fonts** (Space Grotesk, DM Sans and DM Mono) for typography; system fallbacks are included

No JavaScript, frontend framework, backend, build step, paid API or external image asset is required.

## Local preview

Open `index.html` directly in any modern browser—no server or JavaScript runtime needed.

## GitHub Pages deployment

1. Upload `index.html`, `style.css`, `README.md`, `.nojekyll`, and `assets/` to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**, select **`main`** and **`/ (root)`**, and click **Save**.
